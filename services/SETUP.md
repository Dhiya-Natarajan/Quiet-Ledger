# Running QuietLedger Microservices (Identity + Intake + Communication)

## 1. Databases (pgAdmin / PostgreSQL)
Create three databases: `identity_db`, `intake_db`, and `communication_db`.
- Run `services/identity-service/sql/init.sql` in identity_db's Query Tool.
- Run `services/intake-service/sql/init.sql` in intake_db's Query Tool.
- Communication Service manages its own schema automatically via Prisma (`npx prisma db push`).

## 2. identity-service (terminal 1)
```bash
cd services/identity-service
npm install
cp .env.example .env      # fill in your local Postgres password + a JWT_SECRET
npm run dev                # runs on http://localhost:4001
```

## 3. intake-service (terminal 2)
```bash
cd services/intake-service
npm install
cp .env.example .env      # same JWT_SECRET as identity-service; COMMUNICATION_SERVICE_URL=http://localhost:4003
npm run dev                # runs on http://localhost:4002
```

## 4. communication-service (terminal 3)
```bash
cd services/communication-service
npm install
npm run build
npm run dev                # runs on http://localhost:4003
```

*(Note: Communication Service features a zero-config simulation mode that works instantly even if PostgreSQL is not currently running!)*

## 5. Frontend Client (terminal 4)
```bash
cd client
npm install
cp .env.example .env
npm run dev                 # runs on http://localhost:5173
```

## 6. Test the Distributed Microservice Pipeline

1. **Submit a Report via Intake Service**:
   ```bash
   curl -X POST http://localhost:4002/reports \
     -H "Authorization: Bearer <token>" \
     -H "Content-Type: application/json" \
     -d '{"type":"internal","orgId":1,"description":"Safety issue in warehouse","isAnonymous":false}'
   ```
   - `intake-service` calls `identity-service` (Port 4001) to verify org status.
   - `intake-service` asynchronously calls `communication-service` (Port 4003) via REST to dispatch in-app notifications and email alerts.

2. **Verify Notifications**:
   ```bash
   curl http://localhost:4003/notifications?userId=org-1
   ```
   Returns the real-time notification generated by the report submission!
